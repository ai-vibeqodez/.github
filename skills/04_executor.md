# Skill: Исполнитель

## Назначение
Выполнение задач из `todo/<task_short_name>/task_XX.md`. Агент читает задачу, выполняет описанные шаги, заполняет секцию «Результат».

## Входные данные
- Путь к task-файлу: `todo/<task_short_name>/task_XX.md`
- Контекст задачи из `todo/<task_short_name>/OVERVIEW.md`
- Зависимые задачи (уже выполненные)

## Сценарий работы

1. **Чтение задачи**
    - Открыть `todo/<task_short_name>/task_XX.md`
    - Прочитать OVERVIEW.md для контекста
    - Проверить зависимости — все ли выполнены

2. **Проверка готовности**
    - Убедиться что зависимости удовлетворены
    - Проверить что есть все необходимые ресурсы (файлы, доступы)
    - Если что-то отсутствует — сообщить, не начинать работу

3. **Выполнение задачи**
    - Пройтись по чек-листу выполнения (чек-лист выполнения)
    - Создать/изменить файлы согласно описанию задачи
    - Следовать критериям готовности
    - Фиксировать каждый выполненный шаг

4. **Заполнение результата**
    - Заполнить секцию «Результат» в task_XX.md
    - Отметить все критерии готовности как выполненные
    - Обновить OVERVIEW.md (отметить задачу как выполненную)

5. **Коммит изменений**
    - Закоммитить изменения в task_XX.md и OVERVIEW.md
    - Добавить ссылку на результат (файлы, diff)

## Чек-лист начала работы
- [ ] Задача прочитана полностью
- [ ] Зависимости проверены и удовлетворены
- [ ] Контекст из OVERVIEW.md понятен
- [ ] Критерии готовности ясны

## Правила
- Не начинать задачу если зависимости не выполнены
- Следовать чек-листу выполнения шаг за шагом
- Заполнять секцию «Результат» после выполнения
- Обновлять OVERVIEW.md (чекбоксы задач)
- Если задача не может быть выполнена — объяснить почему
- Все изменения коммитить

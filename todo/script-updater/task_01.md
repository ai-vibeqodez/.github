# Task 01: Разработка основного скрипта-апдейтора updater.sh

## Описание
Создать основной скрипт `scripts/updater.sh` — инструмент для проверки и автоматического обновления всех скриптов из центрального репозитория `ai-warevo/.github`.

## Контект
Согласно требованиям, апдейтор должен:
- Проверять наличие обновлений через HTTP (скачивание `updater.sh` из GitHub)
- Сравнивать версии (`SCRIPT_VERSION`)
- Запрашивать согласие пользователя перед обновлением
- Обрабатывать конфликты (изменённые локальные файлы)
- Поддерживать флаги `--version` и `--check-only`
- Синхронизировать все файлы из `scripts/` репозитория
- Обрабатывать ошибки (нет интернета, нет `scripts/` директории)

## Критерии готовности
- [x] Скрипт содержит `SCRIPT_VERSION=1.0.0` в начале
- [x] Реализована проверка версии через HTTP (`curl` к `raw.githubusercontent.com`)
- [x] Реализовано сравнение SemVer версий (X.Y.Z)
- [x] Реализован запрос согласия `[Y/n]` перед обновлением
- [x] Реализована обработка конфликтов (спросить перед перезаписью)
- [x] Реализован флаг `--version` (вывод версии и выход)
- [x] Реализован флаг `--check-only` (проверка без обновления)
- [x] Реализована синхронизация всех `.sh` и `.ps1` файлов
- [x] Обработка ошибок: нет интернета (warn, exit 0), нет scripts/ (error, exit 1), нет SCRIPT_VERSION (warn, skip)
- [x] Логирование с префиксами `[INFO]`, `[WARN]`, `[ERROR]`, `[OK]`
- [x] Коды выхода: 0 — успех/нет обновлений, 1 — ошибка

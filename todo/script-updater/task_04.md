# Task 04: Синхронизация PowerShell-версий (.ps1)

## Описание
Обеспечить синхронизацию PowerShell-версий скриптов (`.ps1`) вместе с bash-версиями (`.sh`) при обновлении.

## Контекст
Каждый проект имеет как `.sh`, так и `.ps1` версии скриптов. Апдейтор должен обновлять обе версии одновременно, включая обновление `SCRIPT_VERSION` в `.ps1` файлах.

## Критерии готовности
- [x] `updater.sh` скачивает и перезаписывает `.ps1` файлы при обновлении
- [x] `SCRIPT_VERSION` обновляется в `.ps1` файлах
- [x] Конфликты проверяются отдельно для `.ps1` файлов
- [x] Все 4 `.ps1` файла синхронизированы во всех проектах
- [x] Версия в `.ps1` совпадает с `.sh`

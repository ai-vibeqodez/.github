# Task 03: Добавить встроенную проверку обновлений в changelog-update.sh и release.sh

## Описание
Добавить автоматическую проверку обновлений при запуске `changelog-update.sh` и `release.sh` через вызов `updater.sh --check-only`.

## Контекст
Когда пользователь запускает `changelog-update.sh` или `release.sh`, они должны автоматически проверить наличие обновлений скриптов (без автообновления) и сообщить пользователю, если обновление доступно.

## Критерии готовности
- [x] `changelog-update.sh` вызывает `updater.sh --check-only` в начале
- [x] `release.sh` вызывает `updater.sh --check-only` в начале
- [x] При наличии обновления выводится: `[INFO] New script updates available. Run: bash scripts/updater.sh`
- [x] При отсутствии обновления — тишина
- [x] Проверка не блокирует выполнение основного скрипта
- [x] Реализовано во всех 4 проектах

# Task 07: Тестирование и валидация всех сценариев

## Описание
Провести полное тестирование всех 7 сценариев использования из требований и убедиться, что система работает корректно во всех 4 проектах.

## Контекст
Перед релизом необходимо проверить все сценарии: обычное обновление, нет обновлений, нет интернета, конфликт файлов, вызов из скрипта, проверка версии, проект без scripts/.

- [ ] Сценарий 4: Конфликт файлов — работает (спросить перед перезаписью)
- [ ] Сценарий 5: Вызов из другого скрипта — работает (--check-only)
- [ ] Сценарий 6: Проверка версии — работает (--version)
- [ ] Сценарий 7: Проект без scripts/ — работает (error, exit 1)
- [ ] Тестирование пройдено во всех 4 проектах
- [ ] `make update` работает во всех проектах

# Script Updater — OVERVIEW

## Цель
Автоматизация синхронизации bash-скриптов (`changelog-update.sh`, `release.sh`, `updater.sh`) из центрального репозитория `ai-warevo/.github` в 4 downstream-проекта (`~/tpl`, `~/.github`, `~/tobus`, `~/template-cpp`). Каждый проект имеет свой апдейтор с проверкой версий по HTTP и запросом согласия перед обновлением.

# Task 02: Создать README.llama-cpp.md

## Описание
Создать файл `README.llama-cpp.md` с документацией по запуску и настройке llama.cpp сервера.

- [ ] Описаны команды `docker compose -f docker-compose.llama.yml up -d` и `down`

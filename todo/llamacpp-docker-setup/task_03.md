# Task 03: Добавить models/ в .gitignore

## Описание
Добавить директорию `models/` в `.gitignore` чтобы избежать коммита скачанных GGUF-моделей (~20GB).

## Контекст
GGUF-модели весят 16-21GB. Их нельзя и не нужно хранить в git. Директория `./models/` используется для локального хранения моделей llama.cpp.

## Критерии готовности
- [ ] `models/` добавлен в `.gitignore` в корне `.github/`
- [ ] Проверено что нет незакоммиченных моделей (если репозиторий уже используется)
- [ ] Файл `.gitignore` содержит другие актуальные игнор-правила из `ollama-fast-coder-4080`

## Чек-лист выполнения
- [ ] Проверить текущий `.gitignore` в `.github/`
- [ ] Добавить `models/` в конец файла
- [ ] При необходимости добавить другие правила из `ollama-fast-coder-4080/.gitignore`
- [ ] Проверить `git status` — ничего лишнего не должно быть

## Зависимости
- Нет (можно делать параллельно с task_01)

## Результат
Модели игнорируются git, репозиторий не раздувается.

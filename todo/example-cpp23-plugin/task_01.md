# Task 01: include/plugin.h — публичный API библиотеки

## Описание
Создать заголовочный файл с публичным API для plugin библиотеки. Функции экспортируются через `__declspec` / `__attribute__` для кроссплатформенности.

## Контекст
Публичный API — единственная точка взаимодействия между plugin и host. Должен быть простым и стабильным.

## Критерии готовности
- [ ] Файл `example/include/plugin.h` создан
- [ ] Декоратор экспорта `PLUGIN_API` для кроссплатформенности
- [ ] Функция `int plugin_version()` — возвращает версию API
- [ ] Функция `int plugin_compute(int a, int b)` — вычисляет результат
- [ ] `extern "C"` для C-совместимости
- [ ] Include guard или `#pragma once`

## Чек-лист выполнения
- [ ] Создать директорию `example/include/`
- [ ] Написать `plugin.h` с API
- [ ] Проверить синтаксис

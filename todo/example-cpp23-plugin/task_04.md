# Task 04: host/src/host.cpp — хост с динамической загрузкой

## Описание
Хост-приложение, которое в рантайме загружает plugin библиотеку через dlopen/LoadLibrary и вызывает её функции.

## Контекст
Host ищет библиотеку: 1) по env var `PLUGIN_PATH`, 2) relative к executable, 3) в стандартных путях. Использует кроссплатформенный код (dlopen на Linux, LoadLibrary на Windows).

## Критерии готовности
- [ ] Файл `example/host/src/host.cpp` создан
- [ ] Кроссплатформенная загрузка (dlopen / LoadLibrary)
- [ ] Поиск библиотеки: env var → relative path → system path
- [ ] `dlsym` / `GetProcAddress` для получения функций
- [ ] Вызов `plugin_version()` и `plugin_compute()`
- [ ] Вывод результата на stdout
- [ ] Обработка ошибок через `std::expected` или аналог

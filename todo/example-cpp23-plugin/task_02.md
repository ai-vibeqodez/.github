# Task 02: plugin/src/plugin.cpp — реализация библиотеки

## Описание
Реализация функций из `plugin.h`. Использует C++23 фичи: `std::format`, `std::source_location`.

## Контекст
Библиотека компилируется в `.dll` (Windows) или `.so` (Linux). Функции вызываются через динамическую загрузку из host.

## Критерии готовности
- [ ] Файл `example/plugin/src/plugin.cpp` создан
- [ ] `plugin_version()` возвращает константу (например, 1)
- [ ] `plugin_compute(a, b)` возвращает `a + b` (или что-то осмысленное)
- [ ] Использует `std::format` для форматирования
- [ ] Использует `std::source_location` для логирования
- [ ] Компилируется как shared library
